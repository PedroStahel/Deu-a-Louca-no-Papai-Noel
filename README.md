# Deu-a-Louca-no-Papai-Noel
Jogo feito como trabalho da matéria de Programação 2 da UFPR, o qual foi desenvolvido em C, utilizando a biblioteca Allegro5, e conta com 1 fase em que você controla o boneco do Papai Noel, o qual está fugindo do Polo Norte após brigar com as renas, que ficaram furiosas e colocaram vários obstáculos para ele ultrapassar
